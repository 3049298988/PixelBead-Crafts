# [PixelBead-Crafts](https://3049298988.github.io/PixelBead-Crafts/)
将图片转化为json以供自动化脚本使用

1，支持json格式导出

2，支持预览拼豆效果

3，目前json格式提供两种兼容： 

[明日方舟-奇象巡演 像素画取色工具](https://prts.chongxi.us/)

[奇象巡展·赛博拼豆制图工具](https://hanako-777.github.io/arknights_draw/)

导入图片推荐  [旅行「像」框](https://tourgrid.miraceo.com/)  或上面的网站导出24x24分辨率，或者1：1比例的图片
